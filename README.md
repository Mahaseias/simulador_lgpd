# Simulador LGPD

Demonstração educativa não oficial com perfis inteiramente fictícios.

- Participante: `usuario.html`
- Painel demonstrativo público: `admin.html`

Não há captura de dados pessoais, autenticação, banco de dados ou transmissão de formulários. O código DEMO-1, DEMO-2 ou DEMO-3 identifica um exemplo fixo, não uma pessoa ou participação comprovada.

Publique a raiz da branch main no GitHub Pages. Consulte LEIA-ME.txt para uso.
