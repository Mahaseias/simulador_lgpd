DEMONSTRAÇÃO DE SEGURANÇA — GITHUB PAGES

Arquivos de entrada: usuario.html e admin.html.
Coloque todos os arquivos desta pasta na mesma pasta publicada pelo seu GitHub Pages.
A página index.html oferece os dois acessos.

FUNCIONAMENTO
1. Abra usuario.html e escolha um dos três perfis fictícios.
2. Clique em Conectar. O alerta vermelho animado aparece.
3. Clique em Abrir painel, ou informe o código DEMO-1, DEMO-2 ou DEMO-3 em admin.html.
4. O painel mostra o perfil fictício correspondente.
Em outro dispositivo, abra admin.html e digite o mesmo código.

LIMITES
Não há coleta de dados reais, banco de dados, envio remoto, registro de visitantes ou atualizações em tempo real. Os códigos identificam apenas exemplos fixos, não comprovam uma participação. O painel é público e não tem autenticação. Não coloque dados reais ou segredos no código-fonte. Os campos do participante são somente leitura para impedir coleta acidental. A senha foi removida. O alerta respeita a preferência de movimento reduzido e possui botão de pausa.

LINKS APÓS A PUBLICAÇÃO
Acrescente /usuario.html e /admin.html ao endereço base do repositório publicado. Não são links ativos antes da publicação. O URL exato depende da conta e do repositório escolhidos.
